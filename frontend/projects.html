Highlighted Projects on Zindi

Insurance Prediction Challenge

A machine learning project from Zindi platform. The goal was to predict the probability of a building having an insurance claim using classification models.

Loan Default Prediction

A machine learning project on loan repayment behavior prediction. The task was to classify loans as either good or bad based on historical data.

Farm to Feed Shopping Basket Recommendation Challenge

This project involved developing a machine learning–based recommender system using historical transaction data to predict the likelihood and quantity of products customers would purchase within 7 and 14 days.

The solution aimed to improve product recommendations, helping optimize sales, reduce food waste, and enhance supply chain efficiency for fresh produce distribution.

data.org Financial Health Prediction Challenge

This project involved building a machine learning classification model to predict the financial health status (Low, Medium, High) of small and medium-sized enterprises using socio-economic and business data.

The solution aimed to support data-driven financial inclusion by helping institutions assess risk, identify vulnerable businesses, and improve access to credit and support services.
